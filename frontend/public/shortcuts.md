# LightDance 鍵盤快速鍵速查表

此文件列出所有可用的鍵盤快速鍵與滑鼠操作，幫助你更有效率地編輯燈光舞蹈。

---

## 播放與導覽

| 快速鍵 | 功能說明 |
|--------|----------|
| **Space** | 播放／暫停音訊 |
| **→** (右方向鍵) | 向前快轉 50 毫秒 |
| **←** (左方向鍵) | 向後倒退 50 毫秒 |
| **Shift + →** | 跳至選取軌道的下一個時間點 |
| **Shift + ←** | 跳至選取軌道的上一個時間點 |
| **A / W / S / D** | 在區塊與軌道之間移動選取（左、上、下、右） |

---

## 時間軸編輯

| 快速鍵 | 功能說明 |
|--------|----------|
| **Delete**／**Backspace** | 刪除選取的區塊 |
| **C** | 在當前時間點切割選取的區塊（僅限選取單一區塊時） |
| **L** | 切換選取區塊的**線性漸變**模式。開啟後，區塊顏色會平滑過渡到下一個區塊 |
| **B** | 開啟選取區塊的**閃爍特效**選單（僅限選取單一區塊時） |
| **P** | 開啟調色盤，修改選取區塊的顏色 |
| **Ctrl + Z** | 復原上一步操作 |
| **Ctrl + Y** | 重做已復原的操作 |

### 移動模式（Move Mode）

按下 **M** 鍵可切換**移動模式**。啟用後：
1. 在彩色區塊上**按住**滑鼠左鍵
2. 左右拖曳來重新定位區塊（會自動對齊 50ms，並保持與左右相鄰區塊的間距）
3. **放開**滑鼠即完成移動

移動模式會一直保持開啟，可以連續拖曳多個區塊；要離開請再按一次 **M**。
若在拖曳到一半時按下 **M**，會先確認當前位置再退出。

> 編輯器左上角的移動圖示按鈕也可切換移動模式（啟用時以藍色高亮顯示）。

## 時間軸縮放

| 操作 | 功能說明 |
|--------|----------|
| **Ctrl / Cmd + 滾輪** | 以游標位置為中心縮放時間軸（Mac 觸控板雙指縮放同樣有效） |
| **滾輪** | 維持原本的捲動 |

以滾輪縮放時，游標下的那個時間點會固定停在原處，方便對準特定段落放大。
使用右下角的 **+ / −** 按鈕或滑桿縮放時，則是讓播放頭置中。

## 複製與貼上

| 快速鍵 | 功能說明 |
|--------|----------|
| **Ctrl + C** | 複製選取的區塊／範圍 |
| **Ctrl + V** | 貼上已複製的區塊，對齊至當前選取區塊的起始位置 |
| **Ctrl + Shift + V** | 貼上已複製的區塊，**保留原始時間戳記** |
| **Shift + C** | 複製選取軌道的**整條時間軸** |
| **Shift + V** | 將整條時間軸貼上至當前選取的軌道（會覆蓋原有內容） |
| **Escape** | 取消複製模式／清除選取 |

## 顏色與亮度

| 快速鍵 | 功能說明 |
|--------|----------|
| **1 – 8** | 將對應的常用顏色套用至選取的區塊 |
| **Ctrl + 1 – 9** | 設定選取區塊的亮度（透明度）為 10% – 90% |
| **Ctrl + 0** | 設定選取區塊的亮度（透明度）為 100% |
| **Shift + 1 – 8** | 在當前時間點插入一個使用對應常用顏色的新區塊 |

## 區塊拉伸模式（Resize）

1. 先選取一個彩色區塊（單擊）
2. 將滑鼠移至區塊的**左側或右側邊緣**，游標會變為調整大小的箭頭（`↔`）
3. 按住邊緣拖曳來調整區塊長度

> 區塊最小持續時間為 **50 毫秒**（定義於 `Timeline.jsx` 中的 `STRETCH_MIN_MS`）。區塊無法縮小至低於此限制。

## 武器／配件編輯

右側的 **AccessoryPanel** 側邊欄可用於編輯有配置武器或配件的舞者（acc0–acc7，即 partIndex 14–21）。

### 選取舞者
- **點擊舞者 SVG 圖示**：選取該舞者，並將其配件配置載入 AccessoryPanel

### 各舞者配件配置

| 舞者 | 武器 | 可編輯部位 |
|------|------|-----------|
| 舞者 1 (armor 0) | 無 | — |
| 舞者 2 (armor 1) | 無 | — |
| 舞者 3 (armor 2) | 螢光繩 | 繩: acc0, acc1 |
| 舞者 4 (armor 3) | 刀 | 刀身: acc0–acc3, 握把: acc4–acc5, 刀柄: acc6–acc7 |
| 舞者 5 (armor 4) | 匕首 | 刀身: acc0–acc1, 握把: acc2–acc3, 刀柄: acc4 |
| 舞者 6 (armor 5) | 無 | — |
| 舞者 7 (armor 6) | 匕首 | 刀身: acc0–acc1, 握把: acc2–acc3, 刀柄: acc4 |

- 點擊側邊欄標題列的 **▲／▼** 可折疊或展開 AccessoryPanel

## 提示

- 操作前請確認已選取正確的軌道與區塊
- 使用 **Ctrl + Z** 可安全復原誤操作
- 編輯過程中資料會自動暫存於本地（IndexedDB），30 天內可復原
