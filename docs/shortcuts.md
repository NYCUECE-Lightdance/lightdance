# LightDance 鍵盤快速鍵速查表

此文件列出所有可用的鍵盤快速鍵與滑鼠操作，幫助你更有效率地編輯燈光舞蹈。

---

## 播放與導覽

| 快速鍵 | 功能說明 |
|--------|----------|
| **Space** | 播放／暫停音訊 |
| **→** (右方向鍵) | 向前快轉 50 毫秒 |
| **←** (左方向鍵) | 向後倒退 50 毫秒 |
| **Shift + →** | 跳至選取軌道的下一個時間點（未選取任何色塊時，退化為向前 50 毫秒） |
| **Shift + ←** | 跳至選取軌道的上一個時間點（未選取任何色塊時，退化為向後 50 毫秒） |
| **A / W / S / D** | 在區塊與軌道之間移動選取（左、上、下、右） |

## 時間軸編輯

| 快速鍵 | 功能說明 |
|--------|----------|
| **Delete**／**Backspace** | 刪除選取的區塊 |
| **C** | 在當前時間點切割選取的區塊（僅限選取單一區塊時） |
| **L** | 切換選取區塊的**線性漸變**模式。開啟後，區塊顏色會平滑過渡到下一個區塊 |
| **B** | 對選取的區塊套用**頻閃**：跳出對話框輸入間隔（毫秒，必須是 50 的倍數，最少 100）。**區塊不會被切開**——閃爍週期記在區塊上，畫面上仍然是一個可拖曳、可改色的區塊，左下角出現一排短豎線表示它在閃。可以一次套到多個選取的區塊；再按一次 B 可以改間隔，輸入 **0** 取消頻閃 |
| **P** | 開啟調色盤，修改選取區塊的顏色 |
| **Ctrl + Z** | 復原上一步操作 |
| **Ctrl + Y** | 重做已復原的操作 |

### 框選（拉一個矩形選多個色塊）

Shift 點擊只能在**同一條**時間軸上加選。要一次選到跨舞者、跨部位的色塊，
直接在時間軸上拉一個矩形：

| 操作 | 功能說明 |
|------|----------|
| 在**空白處**按住拖曳 | 拉出矩形，選取碰到的所有色塊（可跨軌） |
| **Alt + 拖曳** | 從任何地方開始拉，包括被色塊蓋滿的軌道 |
| **Shift + 拖曳** | 把框到的色塊**加進**目前的選取，而不是重新選 |

矩形碰到色塊的任何一部分就選中，不必整段被框住——想選的通常是「這一段時間
裡的東西」，而色塊長度不一，要求完全包住的話會被最長的那一塊綁架。

單純在空白處**點一下**仍然是取消選取（拉不到 4 像素就不算框選），
所以兩種操作不衝突。

### 移動模式（Move Mode）

按下 **M** 鍵可切換**移動模式**。啟用後：
1. 點擊一個彩色區塊開始追蹤
2. 左右移動滑鼠來重新定位區塊
3. 再次點擊任意位置確認新位置並退出移動模式
4. 再次按下 **M** 也會確認當前位置並退出

**多個色塊可以一起搬**：先用 Shift 點擊選起一整段（見上面的多選），再進移動
模式點其中任何一個，整批會用同一個位移量一起移動——相對位置不變，所以搬完
之後樂句的節奏跟原本一樣。整批能移多遠由最靠近未選取鄰居的那一段決定。

點到**沒有被選取**的色塊則視為重新選取，只搬它自己。

> 編輯器左上角的移動圖示按鈕也可切換移動模式（啟用時以藍色高亮顯示）。

## 複製與貼上

| 快速鍵 | 功能說明 |
|--------|----------|
| **Ctrl + C** | 複製選取的區塊／範圍 |
| **Ctrl + V** | 貼上已複製的區塊，對齊至當前選取區塊的起始位置 |
| **Ctrl + Shift + V** | 貼上已複製的區塊，**保留原始時間戳記** |
| **Shift + C** | 複製選取軌道的**整條時間軸** |
| **Shift + V** | 將整條時間軸貼上至當前選取的軌道（會覆蓋原有內容） |
| **Escape** | 取消複製模式／清除選取 |

## 顏色與亮度

| 快速鍵 | 功能說明 |
|--------|----------|
| **1 – 6** | 將調色盤「最愛」第 1–6 格的顏色套用至選取的區塊（該格是空的就不做事） |
| **Ctrl + 1 – 9** | 設定選取區塊的亮度（透明度）為 10% – 90% |
| **Ctrl + 0** | 設定選取區塊的亮度（透明度）為 100% |
| **Shift + 1 – 6** | 在當前時間點插入一個使用對應最愛顏色的新區塊 |

數字對應的是調色盤上「最愛」那一排的六格，由左到右。先前文件寫 1–8，但色票在
2026-08-14 收成一列六格之後，7 與 8 會**繞回第 1、2 格**——按 7 套到的是第 1 格的
顏色，畫面上沒有任何東西顯示這件事。現在超出格數的按鍵不做事。

## 沒有快速鍵的工具列功能

以下功能只能從編輯器上方的工具列操作。

| 位置 | 功能 | 說明 |
|------|------|------|
| **Effect** 選單 → 亮度階梯 | 讓連續色塊的亮度呈階梯變化 | 先選取**一個**色塊，開啟面板設定「起始亮度 / 間隔 / 結束亮度」後按 Apply。系統會從選取的色塊往後，依序把每個色塊的透明度設成 起始 → 起始±間隔 → … → 結束 |
| **半圓形圖示**按鈕 | 統一同色透明度 | 先選取**一個**色塊，再從選單挑一個百分比。**全場所有舞者、所有部位**中與該色塊同色（RGB 相同）的區塊，透明度都會被設成該值 |

> 這兩個功能都要求「恰好選取一個色塊」，否則會跳出提示。

## 區塊拉伸模式（Resize）

1. 先選取一個彩色區塊（單擊）
2. 將滑鼠移至區塊的**左側或右側邊緣**，游標會變為調整大小的箭頭（`↔`）
3. 按住邊緣拖曳來調整區塊長度

> 區塊最小持續時間為 **50 毫秒**（定義於 `Timeline.jsx` 中的 `STRETCH_MIN_MS`）。區塊無法縮小至低於此限制。

## 武器／配件編輯

配件燈（acc0–acc7，即 partIndex 14–21）**畫在光衣卡片裡、與人並排**，
播放時整個人連同手上的東西一起亮。直接點那些小方塊就能放色，和點光衣的部位一樣。

> 2026-08-14 之前它們在右側一個獨立的側欄裡，離所屬的舞者好幾百像素遠，
> 播放時看不出「這位舞者的刀亮了」。那個側欄已經移除。

| 舞者 4 (armor 3) | 刀 | 刀身: acc0–acc3, 握把: acc4–acc5, 刀柄: acc6–acc7 |
| 舞者 5 (armor 4) | 匕首 | 刀身: acc0–acc1, 握把: acc2–acc3, 刀柄: acc4 |
| 舞者 6 (armor 5) | 無 | — |

## 提示

- 操作前請確認已選取正確的軌道與區塊
- 使用 **Ctrl + Z** 可安全復原誤操作
- 編輯過程中資料會自動暫存於本地（IndexedDB），30 天內可復原
